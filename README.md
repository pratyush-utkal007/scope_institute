# SCOPE INSTITUTE

> Professional Computer Coaching & Programming Training — Chandrasekharpur, Bhubaneswar, Odisha.

A high-performance modern web platform built with **React 19**, **Vite**, and **Tailwind CSS v4** featuring hands-on coding tracks, course syllabus explorers, custom admission enquiry modals, and practical learning roadmaps.

## 🚀 Live Demo
- **GitHub Pages**: [https://pratyush-utkal007.github.io/scope_institute/](https://pratyush-utkal007.github.io/scope_institute/)

## 🛠️ Tech Stack
- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4 + PostCSS
- **Routing**: React Router v7
- **Icons**: Lucide React
- **Animations**: AOS (Animate on Scroll)
- **Notifications**: React Hot Toast
- **Deployment**: GitHub Pages (Automated via GitHub Actions)

## 📦 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/pratyush-utkal007/scope_institute.git

# Navigate to project directory
cd scope_institute

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
